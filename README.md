### Hi, I'm Tomáš Sokol

I'm the founder of [Flexity](https://www.flexity.sk/), a Bratislava-based pilates and wellness
company, and the author of [flexi](https://github.com/flexity-git/flexi), an open-source
back-office for Shoptet merchants.

I'm not a full-time developer. I run a business with five Shoptet stores, three studios and a
core team of four. Since March 2026 I've been building our internal system with Claude Code as
my main coding partner, and it now does work we would otherwise need about ten more people for.

**What I'm building in the open**

- [**flexi**](https://github.com/flexity-git/flexi): Shoptet API client, store mirror, stuck
  order alerts, product feeds, an MCP server that connects Claude to your store, and Claude Code
  skills. Apache-2.0. Contributions from other merchants and agencies are welcome.
